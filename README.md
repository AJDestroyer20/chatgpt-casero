# 🤖 CHATGPT CASERO 💬

---

## 📄 Sobre el Proyecto

Este proyecto es una **demostración puramente frontend** que simula la interfaz y el diseño de un chatbot moderno, como ChatGPT.

Está construido únicamente con **HTML**, **CSS** y **JavaScript** para recrear la experiencia visual del usuario, incluyendo el historial de chat y el campo de entrada de texto.

**Importante:** Este repositorio *no* incluye ninguna conexión a un modelo de Inteligencia Artificial real ni a una API de ChatGPT. El objetivo es proporcionar un *esqueleto* visual (una maqueta) para practicar el desarrollo de interfaces de usuario.

---

## 🛠️ Tecnologías

* **HTML:** Estructura de la página.
* **CSS:** Estilos y diseño responsivo.
* **JavaScript:** (Opcional) Funcionalidad básica para simular el envío y la recepción de mensajes.
